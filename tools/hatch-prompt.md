2. **Draft folder.** Create `"{data}/drafts/draft-<timestamp>/source/"` and copy the picture there as `1.<original extension>`. Everything below happens in this draft folder (call it `<draft>`; quote it in commands too).
3. **Pixel art by image processing.** Run `"{data}/venv/bin/python" "{root}/tools/png2dots.py" "<draft>"`, then `"{data}/venv/bin/python" "{root}/tools/pixels.py" preview "<draft>"`, and look at `<draft>/preview.png` with the Read tool (original on top, pixels below).
4. **Touch up.** Edit `<draft>/grid/1.txt` (format: `# palette` lines `x=rrggbb`, then `# pixels`, 32 lines of 32 characters, `.` is transparent). Fix what got mushed — eyes, mouth, cheeks, broken outlines — so it reads clearly. Keep the silhouette from the picture; don't redraw it from scratch. Copy the result to `idle.txt`.
5. **Name and personality.** Ask me what the character is called, then what its personality is like.
6. **What moves.** Look at the picture and suggest which parts could move — for an animal: arms, legs, ears, tail; for a car: wheels, exhaust puffs, the body bouncing; for a train: chimney smoke, wheels; and so on. Let me pick one or more, or describe something else.

8. **How it grows.** dotchi pets grow through 3 stages over a week (stage 1 at the start of the week, stage 3 when the user has worked a lot). Look at the picture and the personality and suggest how this pet should grow: getting **bigger**, gaining **decorations** (a hat, a crown, wings…), wearing **clothes** (a scarf, a cape…), or a mix. Let me pick.

Draw an overlay grid for stage 2 (same format, `.` everywhere except the added pixels) at `<draft>/overlay-2.txt` and run `"{data}/venv/bin/python" "{root}/tools/pixels.py" stage "<draft>" 2 "<draft>/overlay-2.txt"`. Overlays sit at fixed positions: if the part they cover moves between frames, fix those frames' `grid/s2-*.txt` / `grid/s3-*.txt` by hand afterwards.

Move it to `grid/s3-idle.txt` and `grid/s3-1.txt`… , then design smaller stage 1 (`grid/idle.txt`, `grid/1.txt`…) and stage 2 (`grid/s2-*.txt`) versions. Redraw them as a younger, smaller pet; don't just shrink the pixels. Stage 1 should still be clearly recognisable (at least about 16 pixels tall). Keep each stage standing on the same bottom line.
   - Every stage moves the same parts as stage 1, with the same number of frames (1 to 5). Delete the overlay files when done.
